与代码同仓库管理，拥有完整版本历史。
读取数据无需 Token；写入数据需要输入一次 GitHub Token。

📝 如何生成 Token：

  1. 点击 此链接 打开 GitHub Token 生成页
  2. 确认已勾选 repo 权限
  3. 点击页面底部「Generate token」
  4. 复制生成的 ghp_xxxx... 粘贴到上方输入框

⚠️ Token 只会保存在当前手机浏览器中，不会上传到任何地方。
